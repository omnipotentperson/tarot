✦ The Veil ✦
Tarot · Astrology · Divination
The Veil is a high-fidelity, single-page web application designed to bridge the gap between ancient divination and modern technology. It provides users with a digital sanctuary for self-reflection, spiritual guidance, and occult study.

🧭 Core Features
1. Sacred Readings (Draws)
The heart of the application, where users can consult the cards for guidance.

How to Use: Navigate to the Readings tab. Select a spread (e.g., Daily Card, Three-Card Past/Present/Future, or Relationship) and click the Draw button.

Spiritual Aspect: This mimics the physical act of "cutting the deck." It uses a randomized engine to pull cards that reflect the user's current energy, providing a mirror for the subconscious mind to process internal truths.

2. The Fan Draw
A more tactile and intuitive way to select a single card.

How to Use: Enter the Fan Draw section. Use your cursor or finger to hover over the fanned-out deck and click the specific card that "calls" to you.

Spiritual Aspect: This honors the Intuitive Pull. By allowing the user to select a card based on feel rather than a button click, it facilitates a stronger energetic connection between the querent and the digital deck.

3. The Card Library (The Great Archives)
A comprehensive searchable database of all 78 Tarot cards.

How to Use: Browse the Card Library to view high-resolution imagery and deep-dive interpretations. Use the filters to sort by Major Arcana or specific Minor Arcana suits (Wands, Cups, Swords, Pentacles).

Spiritual Aspect: This serves as a Digital Grimoire. It is a tool for study and meditation, allowing practitioners to memorize symbols, elemental associations, and the archetypal journey of the Fool.

4. Celestial Alignment (Astrology & Birth Chart)
A dual-system for tracking planetary influences.

How to Use: Input your date, time, and location of birth to generate a Birth Chart, or check the Astrology tab for daily horoscopes.

Spiritual Aspect: This connects the "Microcosm" (the individual) with the "Macrocosm" (the universe). It provides context on how the movement of the stars affects our emotional tides and destiny.

5. Mystical Reference Guide
A modular encyclopedia for ritual correspondences.

How to Use: Select tabs for Candles, Crystals, Herbs, or Deities. Search for specific items to see their magical properties.

Spiritual Aspect: Every ritual requires the right tools. This guide ensures that the "intent" of a ritual matches the "frequency" of the materials used—such as using a Green Candle for abundance or Amethyst for psychic protection.

🛠️ Technical Overview
Architecture
Frontend: Vanilla JavaScript, HTML5, and CSS3.

UI/UX: Designed with a "Dark/Gold" aesthetic using the Cinzel serif font to evoke the feeling of an ancient parchment scroll.

Data Handling: Uses a modular JSON structure (reference.json, tarot.json) to store mystical correspondences and card meanings.

Installation & Setup
Clone the repository to your local machine or server.

Ensure your folder structure includes:

/data: Containing all JSON archives.

/images: Containing the card deck and iconography.

Open index.html in any modern web browser.

🌙 The Philosophy of The Veil
The Veil is built on the principle that magic is an interface. Just as a physical deck of cards is a tool for the mind, this digital interface acts as a conduit for intention. Whether you are performing a simple daily draw or a deep astrological dive, the application is designed to be a quiet, respectful space for the Great Work.

🗺️ Project Roadmap
The evolution of The Veil follows the cycles of the moon. Future updates are planned to deepen the practitioner's experience and provide more granular control over spiritual data.

🌑 Phase 1: The Waxing Moon (Upcoming Core Features)
Moon Phase Tracker: A real-time lunar widget on the dashboard showing the current phase, sign, and void-of-course status.

Ritual Journal: A localized (browser-based) storage system to save readings, personal notes, and "Aha!" moments from the cards.

Reverse Card Logic: An optional toggle in the Readings engine to allow for reversed card meanings and imagery.

🌓 Phase 2: The First Quarter (Enhanced Astrology)
Transit Overlays: The ability to see how current planetary movements interact with your stored Birth Chart data.

Synastry Reports: A tool to compare two sets of birth data for relationship and platonic compatibility.

Aspect Grid: A technical visualizer for Trines, Squares, and Oppositions within the user's chart.

🌕 Phase 3: The Full Moon (Community & Advanced Tools)
Custom Deck Uploads: Support for users to upload their own card imagery while keeping the core interpretation engine.

Sigil Generator: A canvas tool based on the "Magic Square" (Kamea) method to create custom sigils for digital or physical use.

Export to PDF: The ability to export a beautiful, formatted "Grimoire Page" of a specific reading or astrological report.
